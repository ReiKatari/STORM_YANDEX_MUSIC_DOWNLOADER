## **О проекте**

**STORM YANDEX MUSIC DOWNLOADER** — это специализированное высокопроизводительное приложение для быстрого поиска, пакетного скачивания и каталогизации музыки с сервиса Яндекс Музыка в оригинальном качестве MP3 320 kbps.

Программа разработана на базе современных технологий Tauri (Rust) и React со 100% локализацией на 6 языков, поддержкой 8 визуальных тем оформления, объёмным 3D интерфейсом, контролем уникальности процесса (Single Instance Mode) и работой в фоновом режиме системного трея Windows.

---

## **Ключевые возможности**

- ⚡ **Высокоскоростная загрузка**: многопоточная загрузка аудиофайлов в максимальном качестве 320 kbps с возможностью паузы, возобновления и отмены.
- 📦 **Пакетная обработка дискографий**: выбор и скачивание отдельных треков, популярных списков, альбомов или полной дискографии артиста в один клик.
- 🏷️ **Полные метаданные и обложки**: автоматическое сохранение ID3-тегов (название, артист, альбом, год, номер трека, диск) и вшивание оригинальных обложек высокого разрешения.
- 🔄 **Автоматическая проверка обновлений**: фоновый мониторинг каталогов исполнителей каждые 30 минут с автоматическим обнаружением и загрузкой вышедших новинок.
- 🎨 **8 визуальных тем оформления**: поддержка палитр STORM DARK, STORM NIGHT, STORM DAY, STORM MIDNIGHT, STORM MATRIX, STORM CYBERPUNK, STORM FANTASY и STORM WARHAMMER 40K с мгновенным переключением на лету.
- 🌐 **Мультиязычный интерфейс**: 100% перевод интерфейса на 6 языков (русский, английский, немецкий, французский, китайский, японский).
- 🛡️ **Контроль одного экземпляра**: Single Instance Mode предотвращает случайный запуск дубликатов процесса и мгновенно активирует уже открытое главное окно.
- 📁 **Умная drag and drop интеграция**: удобный выбор целевой папки простым перетаскиванием директории в окно приложения.

## **Установка и запуск**

1. Скачайте инсталлятор `STORM_YANDEX_MUSIC_DOWNLOADER_1.0.1_Setup.exe` или портативный архив `STORM_YANDEX_MUSIC_DOWNLOADER_1.0.1_win-x64.zip` со страницы релизов.
2. Запустите установщик и следуйте простым инструкциям мастера установки.
3. Запустите программу через ярлык на Рабочем столе или в меню Пуск.

---

## **Сборка из исходного кода**

Для сборки проекта требуются установленные компоненты Node.js 18+, Rust 1.77+ и Visual Studio Build Tools C++.

1. Клонируйте репозиторий:
   ```cmd
   git clone https://github.com/ReiKatari/STORM_YANDEX_MUSIC_DOWNLOADER.git
   cd STORM_YANDEX_MUSIC_DOWNLOADER
   ```
2. Установите зависимости:
   ```cmd
   npm install
   ```
3. Выполните сборку:
   ```cmd
   build_installer.bat
   ```
