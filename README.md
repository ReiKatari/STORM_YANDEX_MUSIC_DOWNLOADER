## **О проекте**

**STORM YANDEX MUSIC DOWNLOADER** — это специализированное высокопроизводительное приложение для быстрого поиска, пакетного скачивания, предпрослушивания и каталогизации музыки с сервиса Яндекс Музыка в оригинальном качестве MP3 320 kbps и Lossless FLAC (16/24-bit).

Программа разработана на базе современных технологий Tauri (Rust) и React со 100% локализацией на 6 языков, встроенным музыкальным плеером с 10-полосным эквалайзером и спектральным неоновым визуализатором, поддержкой 8 визуальных тем оформления, объёмным 3D интерфейсом, контролем уникальности процесса (Single Instance Mode) и работой в фоновом режиме системного трея Windows.

---

## **Ключевые возможности**

- ⚡ **Высокоскоростная загрузка в MP3 и Lossless FLAC**: скачивание аудиофайлов в оригинальном студийном качестве (MP3 320 kbps или FLAC 16/24-bit) с паузой, возобновлением и контролем очереди.
- 🎧 **Встроенный плеер предпрослушивания**: потоковое воспроизведение треков прямо в интерфейсе программы, 10-полосный параметрический эквалайзер с пресетами звучания, плавный переход между треками, векторное управление и 4 переключаемых режима неонового визуализатора.
- 📚 **Раздел «Моя медиатека»**: быстрый доступ и пакетное скачивание сборника любимых треков «Мне нравится», плейлистов пользователя и умных персональных подборок дня («Плейлист дня», «Премьера», «Дежавю», «Тайник», «Чарт»).
- 🎤 **Синхронизированный караоке-текст**: автоматическое получение текста песни с таймингами строк, сохранение файлов `.lrc` рядом с треком и вшивание тегов в ID3v2 / Vorbis Comments.
- 🖼️ **Обложки Ultra-HD**: выбор качества обложек от стандартного 600x600 до студийного мастер-арта 2000x2000.
- 📂 **Конструктор структуры папок и файлов**: интерактивная настройка шаблона путей с кликабельными тегами `{Artist}`, `{Album}`, `{Year}`, `{TrackNum}`, `{TrackNum:02d}`, `{Title}`, `{Genre}` с живым предпросмотром.
- 🎛️ **Фильтр «Только оригинал»**: интеллектуальная фильтрация сольного творчества артиста без фитов, ремиксов и сторонних музыкантов.
- 🔄 **Автоматическая проверка новинок**: фоновый мониторинг каталогов исполнителей каждые 30 минут с автоматическим обнаружением и загрузкой вышедших релизов.
- 🎨 **8 визуальных тем оформления**: STORM DARK, STORM NIGHT, STORM DAY, STORM MIDNIGHT, STORM MATRIX, STORM CYBERPUNK, STORM FANTASY и STORM WARHAMMER 40K с мгновенным переключением на лету.
- 🌐 **100% мультиязычный интерфейс**: полный перевод на русский, английский, немецкий, французский, китайский и японский языки.
- 🛡️ **Контроль одного экземпляра**: Single Instance Mode предотвращает случайный запуск дубликатов процесса и мгновенно активирует уже открытое главное окно.

## **Установка и запуск**

1. Скачайте инсталлятор `STORM_YANDEX_MUSIC_DOWNLOADER_0.0.3_Setup.exe` или портативный архив `STORM_YANDEX_MUSIC_DOWNLOADER_0.0.3_win-x64.zip` со страницы релизов.
2. Запустите установщик и следуйте простым инструкциям мастера установки.
3. Запустите программу через ярлык на Рабочем столе или в меню Пуск.

---

## **Сборка из исходного кода**

Для сборки проекта требуются установленные компоненты Node.js 18+, Rust 1.77+ и Visual Studio Build Tools C++.

1. Клонируйте репозиторий:
   ```cmd
   git clone https://github.com/ReiKatari/STORM_YANDEX_MUSIC_DOWNLOADER.git
   cd STORM_YANDEX_MUSIC_DOWNLOADER
   ```
2. Установите зависимости:
   ```cmd
   npm install
   ```
3. Выполните сборку:
   ```cmd
   build_installer.bat
   ```
