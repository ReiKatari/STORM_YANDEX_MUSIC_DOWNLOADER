## **О проекте**

**STORM YANDEX MUSIC DOWNLOADER** — это специализированное высокопроизводительное приложение для быстрого поиска, пакетного скачивания, предпрослушивания и каталогизации музыки с сервиса Яндекс Музыка в оригинальном качестве MP3 320 kbps.

Программа разработана на базе современных технологий Tauri (Rust) и React со 100% локализацией на 6 языков, встроенным музыкальным плеером с 10-полосным эквалайзером и спектральным неоновым визуализатором, поддержкой 8 визуальных тем оформления, объёмным 3D интерфейсом, контролем уникальности процесса (Single Instance Mode) и работой в фоновом режиме системного трея Windows.

---

## **Ключевые возможности**

- ⚡ **100% стабильная загрузка с поддержкой докачки (Resumable Downloads)**: потоковая скачка аудиофайлов с поддержкой HTTP Range (`206 Partial Content`) и временных `.part` файлов. При обрыве связи, отключении питания или повторном запуске загрузка возобновляется ровно с того байта, на котором остановилась.
- 🗃️ **Умное распределение по альбомам и папкам**: каждый альбом сохраняет свою независимую структуру треков и нумерацию. Нахождение одного и того же трека в разных альбомах не считается дубликатом и аккуратно раскладывается по соответствующим каталогам.
- 🚀 **Ограничение параллельных потоков (Semaphore Concurrency)**: контроль очередей на уровне Rust Tokio предотвращает превышение лимитов CDN-серверов и сбросы TCP-сокетов.
- ⚡ **Высокоскоростная загрузка в MP3 320 kbps**: скачивание аудиофайлов в максимальном оригинальном битрейте 320 kbps с паузой, возобновлением и контролем очереди активных загрузок.
- 📚 **Полный доступ к разделу «Моя медиатека» без ограничений**: загрузка всей коллекции «Мне нравится» целиком (без лимита в 300 треков), персональных плейлистов и умных подборок дня с обновленным оформлением без обрезки текста.
- 🔗 **Сквозная быстрая навигация**: мгновенный переход на страницу любого исполнителя и альбома прямо из списков треков, очередей и мини-плеера в один клик.
- 🎧 **Встроенный мини-плеер со статусом качества**: потоковое воспроизведение, отображение активного битрейта потока (`320k`), чистая обложка без рамок с увеличением по клику, 10-полосный параметрический эквалайзер и неоновый спектральный визуализатор.
- 🔍 **Полноэкранный просмотр обложек и фото (Zoom Lightbox)**: модальное окно с надежным каскадным fallback-загрузчиком высокого разрешения (до 2000x2000), лоадером и закрытием по Esc/клику.
- 📁 **Удобный Drag-and-Drop выбор папки сохранения**: перетаскивание папок прямо из Проводника Windows с тактильной неоновой подсветкой зоны захвата.
- 🗂️ **Группировка активных загрузок по артистам (Аккордеон)**: компактный свернутый список загрузок по каждому исполнителю с групповыми кнопками «Пауза», «Возобновить», «Отмена», суммарным объемом в МБ и плавной прокруткой.
- 🚀 **Сверхплавный интерфейс 120 FPS и виртуализация списков**: компонент Virtual Scrolling рендерит только видимые строки, обеспечивая моментальную прокрутку огромных коллекций и дискографий на тысячи треков без подвисаний.
- 🖼️ **Чистый дизайн без паразитных рамок и ленивая подгрузка (LQIP)**: аккуратные бесшовно оформленные карточки альбомов и артистов с плавной анимацией появления.
- ⌨️ **Быстрый поиск по клавише Enter**: мгновенный запуск поиска композиций без лишних кликов мыши.
- 🔢 **Единый стандарт форматирования чисел**: отображение счетчиков слушателей с пробелом между тысячными (`2 142 123`) и полной локализацией на 6 языков.
- 💎 **Супер-объемный 3D-стиль кнопок и редизайн кнопки «Выйти»**: глубокие реалистичные тени, физический тактильный рельеф при наведении и элегантный темно-рубиновый стиль кнопки выхода.
- 🎤 **Синхронизированный караоке-текст**: автоматическое получение текста песни с таймингами строк, сохранение файлов `.lrc` рядом с треком и вшивание тегов в ID3v2.
- 📂 **Конструктор структуры папок и файлов**: интерактивная настройка шаблона путей с кликабельными тегами `{Artist}`, `{Album}`, `{Year}`, `{TrackNum}`, `{TrackNum:02d}`, `{Title}`, `{Genre}` с живым предпросмотром.
- 🎛️ **Фильтр «Только оригинал»**: интеллектуальная фильтрация сольного творчества артиста без фитов, ремиксов и сторонних музыкантов.
- 🔄 **Автоматическая проверка новинок**: фоновый мониторинг каталогов исполнителей каждые 30 минут с быстрым хэш-индексом файлов и автоматическим обнаружением релизов.
- 🎨 **8 визуальных тем оформления**: STORM DARK, STORM NIGHT, STORM DAY, STORM MIDNIGHT, STORM MATRIX, STORM CYBERPUNK, STORM FANTASY и STORM WARHAMMER 40K с мгновенным переключением на лету.
- 🌐 **100% мультиязычный интерфейс**: полный перевод на русский, английский, немецкий, французский, китайский и японский языки.
- 🛡️ **Контроль одного экземпляра**: Single Instance Mode предотвращает случайный запуск дубликатов процесса и мгновенно активирует уже открытое главное окно.

## **Сборка из исходного кода**

Для сборки проекта из исходного кода требуются установленные компоненты Node.js 18+, Rust 1.77+ и Visual Studio Build Tools C++.

1. Клонируйте репозиторий:
   ```cmd
   git clone https://github.com/ReiKatari/STORM_YANDEX_MUSIC_DOWNLOADER.git
   cd STORM_YANDEX_MUSIC_DOWNLOADER
   ```
2. Установите зависимости:
   ```cmd
   npm install
   ```
3. Выполните сборку:
   ```cmd
   npm run build
   npm run tauri build
   ```
   Либо запустите скрипт полной компиляции инсталлятора:
   ```cmd
   build_installer.bat
   ```
4. Для запуска в режиме разработки:
   ```cmd
   npm run tauri dev
   ```
